# Концепция проекта: Scientific Cat

*Scientific Writing, Modernized*

---

## 1. Философия проекта

**Scientific Cat** — это мост между классическим научным набором (как Scientific Word) и современными стандартами. Программа не копирует Scientific Word, а переосмысляет его принципы с учётом 30-летнего прогресса в технологиях.

**Ключевые принципы:**
- **WYSIWYG с математикой** — формулы выглядят как формулы, а не как код LaTeX
- **Открытый формат** — XML, читаемый человеком, не требует программы для чтения
- **Экспорт без потерь** — PDF, DOCX, HTML, LaTeX
- **Привычный интерфейс** — визуальный редактор формул поверх текстового документа
- **Современная основа** — Python + PySide6 + Qt WebEngine для формул

## 3. Основные сценарии использования

### 3.1. Написание статьи
```
Открыть шаблон «Статья» → Набрать текст
→ Вставить формулы через диалог конструктора
→ Добавить цитаты и список литературы
→ Экспорт в PDF
```

### 3.2. Конспектирование
```
Создать новый документ → Вставить формулу кликами мышью
→ Сохранить в формате .sdoc → Открыть на любом ПК
```

### 3.3. Редактура
```
Открыть DOCX/MD → Исправить формулы через WYSIWYG
→ Экспорт в формат журнала
```

## 5. Отличия от Scientific Word

| Фича | Scientific Word | Scientific Cat |
|---|---|---|
| **Платформа** | Windows 95/XP | Кроссплатформенный (Win/Mac/Linux) |
| **Формат файла** | Собственный бинарный | Открытый XML (`.sdoc`) |
| **Формулы** | WYSIWYG (ограничено) | WYSIWYG + полная кириллица |
| **Кириллица** | Частичная / проблемная | Полная поддержка (UTF-8) |
| **Экспорт** | RTF, DVI | PDF, DOCX, HTML, LaTeX, MD |
| **Редактирование** | Двойной режим (текст/формула) | Единое окно |
| **Библиография** | Отсутствует | Встроенный менеджер BibTeX |
| **Шаблоны** | Нет | Статья, диссертация, доклад, конспект |

## 6. Визуальная концепция

### 6.1. Стилистика
- Минималистичный, «чистый» интерфейс
- Тёмная и светлая тема
- Панели инструментов с иконками в стиле Flat/Modern
- Боковая панель для навигации по разделам документа

### 6.2. Иконка
- Минималистичный кот с математической формулой (символ)
- Формат SVG, масштабируемый для любого разрешения
