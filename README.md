# Scientific Cat

**Профессиональный научный редактор** — WYSIWYG-редактор научных документов
с поддержкой математических формул, кириллицы и экспортом в PDF/DOCX/HTML/LaTeX.

Наследует принципы Scientific Word, но переосмыслен на современной основе:
Python + PySide6 + KaTeX + открытый XML-формат `.sdoc`.

Версия: **1.0.0** (SemVer). История: [`CHANGELOG.md`](CHANGELOG.md).

## Возможности

- WYSIWYG-редактор текста: заголовки H1–H6, списки, выравнивание, Bold/Italic/Underline, под/надстрочный.
- Математические формулы (LaTeX) с WYSIWYG-диалогом и live-превью через KaTeX.
- Палитра символов (греческие, математические, кириллица, спецсимволы).
- Живой предпросмотр (KaTeX) с дебаунсингом.
- Библиография: импорт BibTeX, цитирования, список литературы (GOST/APA/IEEE).
- Экспорт: PDF, DOCX, HTML, LaTeX, Markdown.
- Перекрёстные ссылки и авто-нумерация разделов/формул.
- Панель навигации по заголовкам, поиск и замена (Ctrl+F / Ctrl+H).
- Undo/Redo, автосохранение, темы (светлая/тёмная), логирование и crash-дампы.
- Открытый формат `.sdoc` (XML) с XSD-схемой — единственным источником истины.

## Установка

```bat
setup_env.bat
```

Скрипт создаёт `venv` и устанавливает зависимости. Для установки с последующим
прогоном всех проверок используйте `setup_env.bat --check`.

## Запуск из исходников

```bat
run.bat
```

## Запуск собранной версии

```bat
build.bat            :: Windows — собирает dist\ScientificCat\ScientificCat.exe
./build.sh           :: Linux/macOS — собирает dist/ScientificCat/
```

## Примеры

Создание, редактирование и экспорт документа автоматизированы в
[`tests/test_export_integration.py`](tests/test_export_integration.py):
создание → сохранение `.sdoc` → загрузка → экспорт LaTeX/HTML/DOCX.

Готовые шаблоны документов (статья, диссертация, отчёт, лекция, рецензия):
`assets/templates/`.

## Качество

```bat
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m mypy core
```

Интеграционный прогон всех проверок: `setup_env.bat --check`.

## Структура проекта

| Слой | Описание |
|---|---|
| `core/` | Модель документа, парсер/сериализатор `.sdoc`, формулы, экспорт, библиография, ссылки, IR |
| `ui/` | Главное окно, редактор, превью, диалог формул, палитра, поиск/замена, навигация |
| `services/` | Автосохранение, undo/redo, настройки, логирование, пути к ресурсам |
| `assets/` | Схема XSD, стили QSS, шаблоны, KaTeX |
| `tests/` | Юнит- и интеграционные тесты, фикстуры `.sdoc` |

## Формат `.sdoc`

Открытый, читаемый XML-формат. Схема: `assets/schema/sdoc-v1.0.xsd`
(единственный источник истины). Фикстуры: `tests/fixtures/`.
