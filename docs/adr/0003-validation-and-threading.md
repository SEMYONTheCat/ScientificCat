# ADR-0003: Валидация LaTeX (pylatexenc) и поток автосохранения (QTimer)

- **Статус:** Accepted
- **Дата:** 2026-08-18
- **Связанные документы:** [`FS.md`](../../FS.md) §4.2, §5.2, §9.1; [`TZ.md`](../../TZ.md) §2.3, §2.5

## Контекст

Два независимых дефекта в спецификации:

1. **Валидация LaTeX через `sympy.parsing.latex`.**
   Этот модуль экспериментален и не разбирает матрицы, `\begin{...}`-окружения,
   многие команды — даёт ложные ошибки на валидном LaTeX. Плохо влияет на UX
   диалога формул (Фр-08).

2. **Автосохранение через `threading.Timer`.**
   Фоновый поток вызывает `document.save()`, внутри которого используются
   Qt-виджеты/`QTextDocument`. Qt запрещает работу с виджетами вне GUI-потока,
   что ведёт к гонкам и крашам.

## Решение

1. **Валидация — `pylatexenc` + KaTeX.**
   - `pylatexenc.latex2text`/`latexwalker` — строгий синтаксический разбор
     (надёжнее sympy).
   - KaTeX с `throwOnError` — вторая линия проверки на совместимость
     с используемым рендером.
   - `sympy` исключается из обязательных зависимостей; остаётся только как
     опциональная символьная проверка (не для валидации синтаксиса).

2. **Автосохранение — `QTimer` в GUI-потоке.**
   - `AutoStore` работает на `QTimer.singleShot`/периодическом `QTimer`
     внутри главного потока Qt — никаких фоновых потоков для
     обращения к документу.
   - Тяжёлая сериализация XML при необходимости выносится в
     `QThreadPool`/`QRunnable` **только** на этапе записи файла
     (после построения строки в GUI-потоке), либо через `QtConcurrent`.
   - Интервал — из `user_settings.json` (`auto_save_interval`, по умолчанию 300 с).

## Последствия

- Устраняется thread-safety-дефект автосохранения.
- Валидация формул становится точной и быстрой.
- `sympy` становится опциональной зависимостью — уточняется в `requirements.txt`
  на этапе реализации (Этап 1 TODO.md).

## Результат спайка (2026-08-18)

**Подтверждено** на `spikes/spike_katex.py`:
- `pylatexenc` **лоялен**: не поднимает исключение на битой формуле
  `x^ + \frac{` (только предупреждение). Годится как быстрая структурная
  проверка, но не как единственный валидатор.
- **KaTeX с `throwOnError:true` — авторитетная проверка**: ловит
  `Unexpected end of input in a macro argument`. Двухуровневая схема
  (pylatexenc → KaTeX) подтверждена и будет реализована в `FormulaEngine`.
- `align`-окружение валидно только в display-режиме — валидатор/рender
  должны учитывать `displayMode`.
