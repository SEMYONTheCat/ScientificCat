# ADR-0010: Плавающие объекты и подписи (figure/table)

- **Статус:** Accepted
- **Дата:** 2026-08-18
- **Связанные документы:** [`FS.md`](../../FS.md) §2.1 (XSD), §2.3 (нумерация); [`TZ.md`](../../TZ.md) §2.2 (Т-06); [`ADR-0004`](0004-sdoc-format-and-module-structure.md)

## Контекст

В модели есть `Table`/`Figure`, но нет концепции **плавающего объекта**:
позиционирования (here/top/bottom), подписи с авто-нумерацией и списка
объектов. В научных документах таблицы и рисунки перемещаются редактором
верстки, а нумерация обновляется автоматически — этого в текущем формате нет.

## Решение

1. **Расширение XSD элементами плавающих объектов:**
   ```xml
   <float-object id="fig1" kind="figure|table" placement="here|top|bottom">
       <caption>Подпись с авто-номером</caption>
       <content>...table или resource(изображение)...</content>
   </float-object>
   ```

2. **Авто-нумерация** по правилам FS §2.3 (рисунок 1, таблица 1…);
   подпись отображается под/над объектом (по `kind`).

3. **Список объектов** ведётся через `named-objects` (уже в формате):
   каждый плавающий объект регистрируется с `type="figure"|"table"` и
   `label` — это же основа для перекрёстных ссылок (ADR-0011).

4. **Рендер/экспорт:** позиция `here` уважается всегда, `top/bottom`
   применяется в PDF-компоновке (QPrinter/TeX); в HTML — как есть.

## Последствия

- Научная вёрстка становится полноценной (движущиеся объекты + подписи).
- Требует обновления XSD-плана в FS §2.4 и парсера/сериализатора.
- Зависит от ADR-0011 для перекрёстных ссылок на объекты.
