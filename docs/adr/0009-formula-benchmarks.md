# ADR-0009: Бенчмарки конвейера формул

- **Статус:** Accepted
- **Дата:** 2026-08-18
- **Связанные документы:** [`TZ.md`](../../TZ.md) §4.1; [`ADR-0002`](0002-rendering-pipeline.md); [`ADR-0007`](0007-sdoc-fixtures-and-roundtrip.md)

## Контекст

ТЗ §4.1 задаёт метрики производительности: вставка формулы < 200 мс,
scroll-рендеринг 60 fps. Без инструмента измерения метрики неконтролируемы
и «плавают» по мере роста кода.

## Решение

1. **Каталог `tests/benchmarks/`** с измеримыми сценариями на базе фикстур
   (ADR-0007):
   - `latex_to_html` / `latex_to_svg` / `latex_to_png` — латентность на
     корпус типовых формул (дроби, интегралы, матрицы);
   - полный рендер документа (Editor → IR → Preview) — задержка до превью;
   - загрузка и сохранение `.sdoc` большого объёма (100-страничный).

2. **Формат результата:** простое измерение времени + печать в лог/отчёт;
   пороговые значения как **warn/fail** (не жёсткий блок в обычном CI,
   жёсткий — в ночном прогоне).

3. **Метрики привязаны к целям ТЗ:** «вставка < 200 мс» трактуется как
   время от открытия диалога до первого превью, «60 fps» — как время
   полного перерендера превью < 16.7 мс при инкрементальном обновлении
   (см. ADR-0014).

## Последствия

- Производительность измеряется и защищается от регрессий.
- Явная интерпретация метрик ТЗ вместо «на глаз».
- Отдельный ночной CI-джоб для бенчмарков (ADR-0008).
