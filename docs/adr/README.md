# Architecture Decision Records (ADR)

Данный каталог фиксирует ключевые архитектурные решения проекта **Scientific Cat**.
Каждый ADR оформлен по шаблону **Status / Context / Decision / Consequences** и является
неизменяемым источником истины для дальнейшей разработки.

Порядок прочтения — по возрастанию номера. Решения принимались на основе анализа
спецификаций [`TZ.md`](../../TZ.md), [`Concept.md`](../../Concept.md), [`FS.md`](../../FS.md).
