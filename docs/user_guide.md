# Руководство пользователя Scientific Cat

Научный редактор **Scientific Cat** позволяет создавать, редактировать и
экспортировать научные документы с математическими формулами и кириллицей.

## 1. Запуск

Из исходников:

```bat
.venv\Scripts\python.exe main.py
```

Из собранной версии: запустите `ScientificCat.exe` (Windows) или
`ScientificCat` (Linux/macOS) в каталоге `dist/ScientificCat/`.

## 2. Создание и открытие документов

- **Файл → Новый** (`Ctrl+N`) — создать пустой документ.
- **Файл → Открыть...** (`Ctrl+O`) — открыть `.sdoc`.
- **Файл → Открыть Markdown...** — импортировать `.md`.
- **Файл → Сохранить** (`Ctrl+S`) / **Сохранить как...** (`Ctrl+Shift+S`).

Формат файла — открытый XML `.sdoc` (схема `assets/schema/sdoc-v1.0.xsd`).

## 3. Редактирование текста

- **Правка → Жирный** (`Ctrl+B`), **Курсив** (`Ctrl+I`), **Подчёркнутый** (`Ctrl+U`).
- Под/надстрочный индекс — кнопки на панели инструментов.
- **Отменить** (`Ctrl+Z`) / **Повторить** (`Ctrl+Y`).
- **Найти...** (`Ctrl+F`) и **Заменить...** (`Ctrl+H`) — поиск по тексту и формулам,
  с опциональным учётом регистра.
- Заголовки и выравнивание — соответствующие кнопки на панели.

## 4. Математические формулы

- **Вставка → Формула** (`Ctrl+M`) — открыть WYSIWYG-диалог.
- Выберите шаблон (дробь, корень, интеграл, сумма, матрица, греческие буквы)
  или введите LaTeX вручную — превью обновляется в реальном времени.
- Выберите тип **Inline** (в строке) или **Display** (отдельным блоком).
- **Вставка → Перекрёстная ссылка** (`Ctrl+Shift+R`) — вставить ссылку
  «см. уравнение (N)»; номера обновляются автоматически.

## 5. Библиография

- **Файл → Импорт BibTeX...** — импортировать записи из `.bib`.
- Список литературы генерируется в стилях GOST, APA или IEEE.

## 6. Навигация

- Панель **Навигация** (слева) — оглавление из заголовков; клик переводит
  курсор к разделу и обновляется автоматически при изменении структуры.

## 7. Предпросмотр

- Справа от редактора — живой HTML-предпросмотр с рендерингом формул KaTeX.
- Обновляется с задержкой после ввода (дебаунсинг).

## 8. Экспорт

- **Файл → Экспорт...** (`Ctrl+E`) — выбрать формат:
  - **PDF** — через QtPrinter;
  - **DOCX** — через python-docx (формулы встраиваются как PNG);
  - **HTML** — с подключением KaTeX;
  - **LaTeX** — пакет `amsmath`.
- **Файл → Экспорт Markdown** — экспорт в `.md`.

## 9. Шаблоны документов

Готовые шаблоны: `assets/templates/` (статья, диссертация, отчёт, лекция,
рецензия) — используйте как основу для новых документов.

## 10. Автосохранение, темы и логи

- Автосохранение — по таймеру (интервал настраивается в `services/settings.py`).
- **Вид → Светлая/Тёмная тема** — переключение оформления.
- Логи и crash-дампы хранятся в `%APPDATA%/ScientificCat/` (logs/, crashes/).

## 11. Горячие клавиши
