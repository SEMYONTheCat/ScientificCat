# Техническое Задание: Scientific Cat v1.0

## 1. Общие сведения

### 1.1. Наименование
Профессиональный научный редактор **Scientific Cat**

### 1.2. Назначение
Редактирование, вёрстка и экспорт научных документов с поддержкой математических формул

### 1.3. Цели и задачи
- Предоставить удобный WYSIWYG-редактор формул
- Обеспечить полную поддержку кириллицы (UTF-8, Unicode)
- Сохранить совместимость с Markdown и LaTeX
- Экспорт в PDF с сохранением формул
- Создать открытый, читаемый формат файлов

---

## 2. Функциональные требования

### 2.1. Система файлов

| № | Требование | Описание |
|---|---|---|
| Ф-01 | Формат `.sdoc` | XML-based, читаемый человеком, версионируемый |
| Ф-02 | Версионирование | XML-атрибут `version="1.0"` в корне документа |
| Ф-03 | Совместимость | Backward compatible в рамках major версии (1.x) |
| Ф-04 | Кодировка | UTF-8, без исключений |
| Ф-05 | Вложения | Изображения и шрифты хранятся как base64 в XML |
| Ф-06 | Автосохранение | Каждые 5 минут + recovery-файл при падении |

### 2.2. Редактирование текста

| № | Требование | Описание |
|---|---|---|
| Т-01 | Базовое форматирование | Bold, Italic, Underline, Subscript, Superscript |
| Т-02 | Заголовки | 6 уровней (h1–h6) |
| Т-03 | Параграфы | Выравнивание (left/center/right/justify) |
| Т-04 | Списки | Упорядоченные и неупорядоченные |
| Т-05 | Цитаты | Блочные цитаты с оформлением |
| Т-06 | Таблицы | До 20×20, объединение ячеек (опционально) |
| Т-07 | Markdown | Импорт и экспорт `.md` |
| Т-08 | Поиск и замена | По тексту, с учётом регистра |

### 2.3. Редактирование формул

| № | Требование | Описание |
|---|---|---|
| Фр-01 | WYSIWYG диалог | Отдельное окно с визуальным конструктором |
| Фр-02 | Шаблоны формул | Дроби, корни, интегралы, суммы, греческие буквы, подстрочные/надстрочные индексы |
| Фр-03 | Ввод символов | Таблица символов с поиском (кириллица + греческие + спецсимволы) |
| Фр-04 | Live preview | Реалтайм предпросмотр формулы через KaTeX |
| Фр-05 | Ввод LaTeX | Текстовое поле для ручного ввода LaTeX-кода |
| Фр-06 | Типы формул | Inline (в тексте) и Display (блочные, центрированные) |
| Фр-07 | Нумерация формул | Автоматическая нумерация с возможностью ручного управления |
| Фр-08 | Валидация | Проверка LaTeX-синтаксиса через `sympy.parsing.latex` |

### 2.4. Рендеринг и экспорт

| № | Требование | Описание |
|---|---|---|
| Р-01 | Live preview | Разделённый экран: Editor ↔ Preview |
| Р-02 | Экспорт PDF | Через QPrinter, формулы рендерятся как SVG |
| Р-03 | Экспорт DOCX | Через `python-docx`, формулы → изображения |
| Р-04 | Экспорт HTML | С встроенным KaTeX CDN |
| Р-05 | Экспорт LaTeX | Полная конвертация .sdoc → .tex |
| Р-06 | Zoom | 50%–400%, масштабирование интерфейса |

### 2.5. Управление документами

| № | Требование | Описание |
|---|---|---|
| У-01 | Шаблоны | Статья, доклад, конспект, диссертация, рецензия |
| У-02 | Автосохранение | Каждые 5 минут + recovery-файл |
| У-03 | Версионирование | История файлов в `.sdoc/history/` |
| У-04 | Несколько документов | MDI или tabbed интерфейс |
| У-05 | Последовательность | Восстановить последние документы при запуске |

### 2.6. Библиография

| № | Требование | Описание |
|---|---|---|
| Б-01 | BibTeX импорт | Импорт `.bib` файлов |
| Б-02 | Цитирование | Вставка ссылок `[1]`, `[2]` в текст |
| Б-03 | Авто-нумерация | Перенумерация при удалении/добавлении |
| Б-04 | Генерация списка | Автоматическое создание списка литературы |
| Б-05 | Стили цитирования | GOST, APA, IEEE (минимум) |

## 4. Нефункциональные требования

### 4.1. Производительность

| Метрика | Целевое значение |
|---|---|
| Загрузка 100-страничного документа | < 3 сек |
| Вставка формулы (от открытия до превью) | < 200 мс |
| Scroll-рендеринг | 60 fps |
| Автосохранение | Фоновый поток, не блокирующий интерфейс |

### 4.2. Совместимость

| Платформа | Минимальная версия |
|---|---|
| Windows | 10 (64-bit) |
| macOS | 12 (Monterey) |
| Linux | Ubuntu 22.04 / Fedora 36+ |

| Параметр | Значение |
|---|---|
| **Язык** | Python 3.10+ |
| **GUI** | PySide6 6.5+ |
| **RAM** | 2 GB minimum, 4 GB recommended |
| **Диск** | 200 MB для установки + ресурсы |

### 4.3. Безопасность

| Требование | Описание |
|---|---|
| Кодировка | Исключительно UTF-8 |
| Валидация XML | `lxml` с схемами XSD |
| Sandboxing парсеров | Ограничение ресурсов при парсинге Markdown/XML |
| Безопасный импорт | Проверка `.bib`, `.md`, изображений перед загрузкой |

### 4.4. Надёжность

| Требование | Описание |
|---|---|
| Crash-recovery | Восстановление несохранённых данных из `.sdoc.recover` |
| Logging | Детальный лог в `%APPDATA%/ScientificCat/logs/` |
| Error reporting | Диалог с кодом ошибки (для разработчиков) |

## 6. Критерии приёмки

| № | Критерий | Как проверяется |
|---|---|---|
| 1 | Документ .sdoc открывается и сохраняется без потери данных | Экспорт-импорт цикл |
| 2 | Формула отображается одинаково в Editor и Preview | Визуальное сравнение |
| 3 | Экспорт PDF сохраняет форматирование и формулы | Открытие PDF |
| 4 | Кириллица корректно отображается везде | Тестовый документ с кириллицей |
| 5 | Markdown-файл корректно импортируется | Импорт .md → .sdoc |
| 6 | Автосохранение срабатывает через 5 минут | Таймер + проверка recovery-файла |
| 7 | Библиография генерируется автоматически | Вставка цитат → проверка списка |
